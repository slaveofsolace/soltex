# Capability matrix

This matrix describes product requirements without claiming copied implementation or brand parity.

| Area | Current WaveSlate | Future product work | Nonclaim |
| --- | --- | --- | --- |
| Antivirus health | WSC aggregate health, change notifications, polling recovery, and Defender mode/details | Optional provider-name inventory | WaveSlate is not a registered provider |
| File scanning | Defender quick/custom scans plus bounded, path-redacted Operational event correlation | Longer-lived scan progress UX | No proprietary detection engine |
| Intake protection | AMSI, hash, signed manifest, Authenticode | Strict archive staging and publisher pinning | Clean AMSI is not universal trust |
| Quarantine | Authenticated index, restore/delete | Protected-service hardening if product scope changes | Not tamper-proof against same-user malware |
| Allow list | Exact SHA-256 only | Signed enterprise policy if needed | No path/folder Defender exclusions |
| Web/exploit/ransomware | None | Separate evaluated product tracks | No Malwarebytes-equivalent layer claim |
| Audio | Navigation placeholder | WASAPI DSP, endpoints, APO/driver | No live routing today |
| Clips | Navigation placeholder | WGC/D3D11/MF segment pipeline | No live capture today |
| Remote Assist | Current-source external RustDesk selection/trust gate, fixed share/connect launch plans, and explicit confirmation | Official-release provenance policy, managed lifecycle, compatibility/accessibility validation | No embedded transport, credential handling, unattended access, relay, or native remote-control engine |
| Visual system | Current-source Zen-inspired warm dark workspace, compact numbered nav, editorial hierarchy, and asymmetric Remote Assist canvas | Native render evidence, keyboard/accessibility pass, responsive refinement, human visual acceptance | No Zen branding, assets, or 1:1 UI copy |
