OWNER-DERIVED PRODUCT DIRECTION
1. RustDesk is visible, consent-based remote hands—not the command brain.
2. Future automation uses a small, capability-bounded agent on each Windows/Mac device. Do not expose a generic remote shell.
3. Tailscale is a separately installed optional private mesh. Reachability is never authorization; do not open public ingress or alter ACLs silently.
4. The NAS stores shared files, indexes, backups, and permitted redacted logs—not credentials, permissions, device keys, or authoritative commands.
5. Unified search should span approved local files, NAS, notes, and Google Drive while always showing provenance.
6. Google Drive is a personal read-write target: search, upload/download, folder creation, move, rename, trash/restore, a `Solace Inbox`, and bounded directional sync.
7. Box is a separate work trust domain with separate credentials, index, audit, process/profile, and UI identity. No personal/work/NAS/AI crossover by default.
8. Voice/text AI intent can propose typed jobs only after deterministic capabilities and device-local policy exist.
9. A per-application audio router belongs in the product, but real WASAPI/APO/driver work must not be faked with UI.
