# Soltex Native Instrument V1 — cold-eye baseline

## Verdict

`REVISE`. The current product is technically coherent and unusually honest about degraded state, but its presentation reads as a generic dark administrative dashboard rather than one mature Windows-native instrument.

## First impression

At three seconds, the large page title and current-status chip win attention. By ten seconds, repeated rounded bordered panels become the visual system. By thirty seconds, the useful data is clear, but the shell still feels assembled from equal-weight modules instead of directed around the current job.

## Anti-template dispositions

- `DELETE`: redundant readiness/status narration that repeats the same state; unused permanent rail space; scaffold copy after the corresponding live gate is actually satisfied.
- `REPLACE`: uniform card framing, generic dashboard composition, and global-warning footer card with unframed workspaces, one primary instrument, compact command/status centers, and progressive diagnostics.
- `KEEP`: real telemetry, explicit current/degraded labels, Applications' searchable data-first table, direct Windows Security handoff, fail-closed Whisper policy, and the absence of decorative blobs or invented metrics.
- `VERIFY`: exact-head render drift, Mica/title-bar/snap behavior, theme switching, high contrast, reduced motion, keyboard flows, scaling, and owner-host physical checks.

## Committed direction

**Quiet Native Instrument**

- Type: Segoe UI Variable for Windows-native hierarchy; Segoe Fluent Icons for semantic glyphs; technical numerics only where they aid comparison.
- Palette: Mica-neutral shell, restrained layered surfaces, one Soltex Glacier accent; green, amber, and red only for real state.
- Layout: responsive native navigation rail, unframed workspaces, and one dominant working surface per module. Repeated bordered entities are allowed only when repetition is the data model.
- Motion: functional 120–180 ms transitions for navigation, drawers, recording state, and causality; OS reduced-motion removes nonessential animation.
- Signature behavior: a live instrument strip binds current machine, protection, audio, and capture state to the module toolbar without turning every fact into a card.
